## Technical SEO

### Findings
- robots.txt was not detected at the site root.
- No sitemap could be discovered from robots.txt or /sitemap.xml.
- No canonical URL was detected.
- Important security headers are missing: content-security-policy, x-frame-options, x-content-type-options, referrer-policy.
- Critical SEO content is not strongly evident in the initial HTML response.

### Recommended Fixes
- Publish a root-level robots.txt that clearly references the sitemap.
- Add a self-referencing canonical tag to stabilize indexation signals.
- Add baseline security headers such as CSP, HSTS, X-Frame-Options, and X-Content-Type-Options.
- Serve titles, canonicals, meta directives, structured data, and key copy in server-rendered HTML.
- Consider IndexNow if faster Bing/Yandex discovery matters to the publishing workflow.
