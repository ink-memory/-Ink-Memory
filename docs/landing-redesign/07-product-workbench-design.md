## 页面目标

- 定位：个人思维模式整理
- 载体：Deck
- 入口：Tasks / Goals / Decks

## 核心链路

`需求 → 目标 / 任务 → 多智能体 → 模块 → 路径 → Deck`

拓扑节点保留角色、状态、交接、来源与结果元信息。

## 交互

- Real Decks：三类案例为真实前端 Tab。案例画布进入视口后固定，再按原生滚轮或触控滚动进度依次切换；点击与方向键作为直接定位和无障碍辅助。
- Sources：平台轨道无缝循环；悬浮或聚焦暂停；Reduced Motion 下停止并开放横向浏览。
- Real Decks / Topology：产品案例用完整画布作为滚动故事；拓扑线与六个节点按滚动进度连续显现。
- Workflow：桌面端下一完整面板随原生滚动持续上移并遮盖上一面板，不使用阈值换页或右侧抽屉按钮。左索引点击、方向键定位对应面板。移动端取消粘性叠层，以完整面板线性浏览。
- Hover：工作台入口、任务行、平台图标、拓扑节点、流程画布显示边框 / 位移 / 阴影反馈。
- Focus：所有链接与按钮使用高对比焦点环。
- Reduced Motion：取消平滑定位、平台自动移动和非必要过渡；面板仍跟随原生滚动位置。
- 无 Loading / Empty / Error：落地页示意数据本地同步；不虚构远程服务状态。
- Blog：分类筛选在前端即时完成；卡片随视口轻量显现；文章目录跟随章节，顶部显示阅读进度；复制链接提供明确完成反馈。
